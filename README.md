## Hi there, I'm Adam Gazdiev.

I'm a system & software engineer who builds the parts that hold things together: backend platforms, integrations, and engineering tools that turn raw data — from payment flows to point clouds — into something reliable and usable.

I care most about what happens beyond the happy path: system boundaries, edge cases, and code that still makes sense years after it ships.

📍 Based in Belgium 🇧🇪

### ⚙️ Engineering Focus

- **Backend systems & integrations** — APIs, authentication, data flows, service boundaries, and payment integrations.
- **3D & geospatial software** — point-cloud processing, terrain analysis, coordinate systems, and CAD-oriented outputs.
- **Engineering tools & automation** — practical software for processing data, simplifying workflows, and reducing manual steps.
